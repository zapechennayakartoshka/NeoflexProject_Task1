В этой папке находятся экспортированные джобы Talend для проекта NeoflexProject_Task1.

## Состав

- 'MD_ACCOUNT_D_Loader.zip' - загрузка лицевых счетов (DS.MD_ACCOUNT_D)
- 'FT_BALANCE_F_Loader.zip' - загрузка остатков (DS.FT_BALANCE_F)
- 'FT_POSTING_F_Loader.zip' - загрузка проводок (DS.FT_POSTING_F)
- 'MD_CURRENCY_D_Loader.zip' - загрузка валют (DS.MD_CURRENCY_D)
- 'MD_EXCHANGE_RATE_D_Loader.zip' - загрузка курсов (DS.MD_EXCHANGE_RATE_D)
- 'MD_LEDGER_ACCOUNT_S_Loader.zip' - загрузка балансовых счетов (DS.MD_LEDGER_ACCOUNT_S)
- 'LOG_ETL_Writer.zip' - логирование (LOGS.ETL_LOG)
- 'MainLoad_All.zip' - паралелльный запуск джобов

## Запуск

1. Распаковать ZIP-архив
2. Запустить `run.bat` (Windows) или `run.sh` (Linux/Mac)
