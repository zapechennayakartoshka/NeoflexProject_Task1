## Разработка ETL-процесса для загрузки банковских данных в PostgreSQL

---

## О проекте

В рамках данного проекта разработан ETL-процесс для загрузки банковских данных из CSV-файлов в СУБД PostgreSQL. Процесс реализован с использованием инструмента **Talend Open Studio for Data Integration**.

---

## План работы:

1. Создать схему 'DS' и таблицы для хранения данных
2. Создать схему 'LOGS' и таблицу для логирования
3. Разработать ETL-процессы для загрузки 6 таблиц
4. Реализовать логирование
5. Обеспечить режим «Запись или замена» (Upsert) для таблиц с первичными ключами 

--- 

## Используется:
 
**ETL-инструмент**: Talend Open Studio for Data Integration v7.1.1	

**СУБД**: PostgreSQL	

**Язык**: Java (генерируется Talend)	

**Форматы данных**: CSV
